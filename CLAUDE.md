# KeremKit - notes for AI agents developing this repository

- **First:** read the private development repository before changing anything:
  `gh repo clone keremgulluuu/keremkit-dev` (or `gh api repos/keremgulluuu/keremkit-dev/contents/...`) ->
  `DEVELOPING.md` (rules), `KeremKit-devam.md` (handoff: state, open items), the newest file in `releases/`.
  No access -> ask the owner; do not guess the rules.
- **Last:** push the updated handoff file and the release report (`releases/X.Y.Z.md`) to that repository.
  The owner reads them there (no local copies unless asked). Details: `CONTRIBUTING.md` -> Maintainer handoff.
- Release checklist, tests and packaging: `CONTRIBUTING.md` and `DEVELOPING.md`.
